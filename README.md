# Portfolio-website
Personal portfolio website created with HTML, CSS, and JavaScript

## Features
- Responsive and clean design
- Personal profile section
- About Me section
- Skills showcase
- Education details
- Projects section
- Contact information
- Interactive button using JavaScript
- Modern card-based grid layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
This project was created to practice and demonstrate the fundamentals of web development, including webpage structure, styling, layouts, and basic interactivity.
